# ADR 004: Use Bootstrap for Frontend Styling and Responsive Design

## Context
The project requires a responsive and user-friendly interface that works across different screen sizes and devices. Developing a consistent layout and reusable UI components from scratch would increase development time and complexity.

## Decision
Bootstrap was selected as the primary CSS framework for frontend styling and responsive design.

## Alternatives Considered
- Tailwind CSS
- Custom CSS

## Reasons
- Provides ready-to-use UI components.
- Simplifies responsive design across different devices.
- Speeds up frontend development.
- Integrates easily with Django templates.
- Provides a consistent design system.

## Consequences
- Reduces frontend development time.
- Makes responsive layouts easier to implement.
- Requires customization to achieve a unique visual identity.
