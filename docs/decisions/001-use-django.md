# ADR 001: Use Django as the Backend Framework

## Context
The project requires a backend framework to manage application logic, communicate with external APIs, and handle market data.

## Decision
Django was selected as the primary backend framework.

## Alternatives Considered
- Flask
- FastAPI

## Reasons
- Built-in administrative interface.
- Integrated ORM and database management.
- Built-in security features.
- Suitable for structured web applications.

## Consequences
- A structured and maintainable codebase.
